Trunk rings — time in the wood

time-axis concept board · variant B

Height is when. One band per quarter, oldest at the roots. Band radius = commits that quarter. Band stripes = the mix (commit / pr / review / issue) — the behavioural maturity signal that used to live in milestones. The crown above is now: the sector compass of the last two quarters.

The mix — stripe width in each ring
Ring thickness is commits only — never total events. A PR's own commits are already in the log, so raw-event thickness would overstate 2026 by ~3× as a workflow artifact. Thickness carries volume; composition carries the mix.
